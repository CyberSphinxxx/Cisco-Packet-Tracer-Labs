# Security Policy

## Reporting Security Issues or Copyright Concerns

The maintainers of **Cisco Packet Tracer Labs** take repository integrity, student data privacy, and intellectual property protection seriously.

If you discover:
1. **Accidental Exposure of Personal Identifiable Information (PII)**: Such as student names, student IDs, or contact information in legacy files or commits.
2. **Proprietary or Copyrighted Academic Materials**: Such as proprietary course assessment files (`.pka`) or official exam solutions that should not be publicly accessible.
3. **Repository Vulnerabilities**: Security flaws in our automation scripts, CI workflows, or validation tooling.

Please report the issue promptly.

---

## Reporting Process

To report a vulnerability, proprietary asset disclosure, or PII leak:
- **Open a private security advisory** via GitHub Security Advisories tab if enabled on this repository, or
- Open a GitHub Issue labeled `confidential-review` detailing the specific file path, commit hash, and reason for concern.

Please include:
- A clear description of the issue.
- Specific file paths, line numbers, or commit SHAs involved.
- Expected corrective action (e.g., quarantine, redaction, or removal).

We will investigate and respond promptly to review the content, quarantine affected assets, and take appropriate remediation measures.
