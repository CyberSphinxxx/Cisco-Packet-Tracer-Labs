## Devices & Topology
- **R1:** Cisco ISR 4321 (Legitimate Gateway & DHCP Server)
  - Gi0/0/0 -> SW-1 Gi0/1 (Uplink, Trusted)
  - IP: 192.168.10.1 /24
  - DHCP Pool: CORP-POOL (192.168.10.10 - 192.168.10.50, GW 192.168.10.1, DNS 192.168.10.1)
- **SW-1:** Cisco Catalyst 2960-24TT (Access Switch)
  - Gi0/1: Uplink to R1 (VLAN 10, Trusted)
  - Fa0/10: Client-1 (VLAN 10, Untrusted)
  - Fa0/11: Client-2 (VLAN 10, Untrusted)
  - Fa0/24: Rogue-Server (VLAN 10, Untrusted)
- **Rogue-Server:** Server-PT (Unauthorized Rogue DHCP Server)
  - Fa0: 10.66.66.1 /24, DHCP Service ON (Offers 10.66.66.100 - 10.66.66.150, GW 10.66.66.1)
- **Client-1:** PC-PT (DHCP Client)
- **Client-2:** PC-PT (DHCP Client)

## Progression
1. **Starter State:**
   - DHCP Snooping DISABLED.
   - Rogue DHCP server active on untrusted port Fa0/24.
   - Client-1 obtains rogue lease (10.66.66.x) or is poisoned, failing communication to 192.168.10.1.
2. **Completed State:**
   - Global `ip dhcp snooping`.
   - `ip dhcp snooping vlan 10`.
   - `no ip dhcp snooping information option`.
   - Gi0/1: `ip dhcp snooping trust`.
   - Untrusted ports Fa0/10, Fa0/11, Fa0/24 untrusted by default, rate limited.
   - Rogue offers blocked; Client-1 and Client-2 lease 192.168.10.x from R1.
   - DHCP snooping binding database populated.

## Verification Matrix
- **POS-01:** R1 interface Gi0/0/0 up/up and DHCP pool CORP-POOL active
- **POS-02:** SW-1 DHCP snooping enabled globally and on VLAN 10
- **POS-03:** SW-1 interface Gi0/1 trusted (`show ip dhcp snooping` -> Gi0/1 yes)
- **POS-04:** Client-1 dynamic lease from legitimate pool (`192.168.10.x`, GW `192.168.10.1`)
- **POS-05:** Client-2 dynamic lease from legitimate pool (`192.168.10.x`, GW `192.168.10.1`)
- **POS-06:** Client-1 ping to default gateway 192.168.10.1 (4/4 replies)
- **POS-07:** SW-1 DHCP snooping binding database verified (`show ip dhcp snooping binding`)
- **NEG-01:** Starter state: Rogue server poisoning demonstration (Client receives rogue IP or rogue offers exist without snooping)
- **NEG-02:** Completed state: Rogue DHCP server offers blocked on Fa0/24 (no binding created for rogue server, client never receives 10.66.66.x)
