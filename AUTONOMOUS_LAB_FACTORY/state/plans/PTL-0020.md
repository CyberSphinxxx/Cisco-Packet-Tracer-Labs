# PTL-0020 — Plan: IPv4 Dynamic PAT at the Edge

- **Candidate task and original educational distinction:** Implement Port Address Translation (NAT Overload) on an edge Cisco ISR 4321 router connecting a private RFC 1918 branch LAN (`192.168.10.0/24`) to an external ISP and simulated public web server on RFC 5737 space (`203.0.113.0/30` and `198.51.100.0/24`). Shows how multiple private hosts share a single public IP address via distinct transport port/identifier mappings without requiring public IP routing inside the ISP.
- **Prerequisites and canonical existing examples checked:** `PTL-0013` (Standard and Extended ACLs) completed and reviewed. Canonical existing lab `labs/network-services/dhcp-server-and-relay` reviewed for style and layout.
- **Packet Tracer version, real available device models/IOS:** Cisco Packet Tracer 9.0.1.0038. Router model: `ISR4321` (IOS-XE 16.6+), Switch model: `Catalyst 2960-24TT`, End devices: `PC-PT` (PC-A, PC-B) and `Server-PT` (Svr-Public).
- **Required command/GUI support probe and actual result:** Probed Cisco ISR 4321 in live simulator: `ip nat inside`, `ip nat outside`, standard ACL, `ip nat inside source list 1 interface GigabitEthernet0/0/1 overload`, and `show ip nat statistics` / `show ip nat translations`. Confirmed 100% native execution.
