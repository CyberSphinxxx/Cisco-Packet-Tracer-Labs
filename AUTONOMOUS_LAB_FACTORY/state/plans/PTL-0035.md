# Lab Design Plan: PTL-0035 - WPA2 Wireless LAN Fundamentals

## 1. Metadata and Identification
- **Lab ID:** PTL-0035
- **Slug:** `wpa2-wireless-lan-fundamentals`
- **Category:** `wireless-wan`
- **Difficulty:** `beginner`
- **Estimated Duration:** 45 minutes
- **Topics:** `["wireless", "wpa2-psk", "access-point", "dhcp", "lan-switching"]`
- **Prerequisites:** `["PTL-0022"]`

## 2. Learning Objectives
1. Configure and deploy a standalone wireless access point (`AccessPoint-PT`) with standard 802.11 parameters.
2. Secure the wireless LAN using WPA2-Personal (Pre-Shared Key / AES encryption).
3. Integrate wireless radio infrastructure with switched Ethernet infrastructure (Catalyst 2960).
4. Configure Cisco IOS DHCP services on `Edge-R1` to dynamically service wireless and wired hosts.
5. Install and configure wireless NIC hardware (`PT-LAPTOP-NM-1W`) on portable host clients.
6. Verify and contrast authorized client access (POS) versus unauthorized authentication failure (NEG).

## 3. Topology Design
```
       [ Edge-R1 ] (ISR4321 - Default Gateway & DHCP Server: 192.168.10.1/24)
           | Gi0/0/0
           |

         /        \
   Fa0/2/          \ Fa0/3
       /            \

   (AccessPoint-PT)

   : : : : : : : : : : : : : : : : : : : : : : :
   ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) ) )
         /                     \
   [ Laptop-1 ]            [ Laptop-2 ]

```

## 4. Addressing Table
| Device | Interface | IP Address | Subnet Mask | Default Gateway | Function |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `Edge-R1` | Gi0/0/0 | `192.168.10.1` | `255.255.255.0` | N/A | LAN Gateway & DHCP Pool |
| `Switch-S1` | VLAN 1 (SVI) | `192.168.10.2` | `255.255.255.0` | `192.168.10.1` | Management SVI |
| `Wired-Server` | FastEthernet0 | `192.168.10.100` | `255.255.255.0` | `192.168.10.1` | Intranet Web/File Server |
| `Laptop-1` | Wireless0 | `192.168.10.51` (DHCP) | `255.255.255.0` | `192.168.10.1` | Authorized Wireless Station |
| `Laptop-2` | Wireless0 | DHCP / Static | `255.255.255.0` | `192.168.10.1` | Unauthorized Wireless Station |

## 5. Security & Wireless Parameters
- **SSID:** `Enterprise-WiFi`
- **Band:** 2.4 GHz (Channel 6 - 2.437 GHz)
- **SSID Broadcast:** Enabled
- **Authentication:** WPA2-PSK
- **Encryption:** AES
- **Pre-Shared Key (PSK):** `CiscoLabKey2026!`

## 6. Verification Matrix
- **POS-01:** `Edge-R1` Gi0/0/0 is up/up with `192.168.10.1/24` and DHCP pool `WLAN-POOL` configured.
- **POS-02:** `Switch-S1` interfaces Fa0/1, Fa0/2, Fa0/3 active with spanning-tree forwarding.
- **POS-03:** `AP-1` SSID `Enterprise-WiFi` active with WPA2-PSK AES encryption enabled.
- **POS-04:** `Laptop-1` equipped with `PT-LAPTOP-NM-1W` associates successfully with `AP-1`.
- **POS-05:** `Laptop-1` acquires valid IP configuration via DHCP (`192.168.10.x`).
- **POS-06:** `Laptop-1` pings default gateway `192.168.10.1` with 100% success rate.
- **POS-07:** `Laptop-1` pings `Wired-Server` `192.168.10.100` across switched boundary with 100% success rate.
- **NEG-01:** `Laptop-2` with incorrect WPA2 passphrase (`InvalidPass999!`) fails to transmit/receive unicast data to `Wired-Server` (100% ping loss).
- **NEG-02:** Station configured with non-existent SSID cannot establish connection.
