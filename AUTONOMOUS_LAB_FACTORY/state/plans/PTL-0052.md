## 2. Learning Objectives & Curriculum Outcomes
- Diagnose and resolve DHCP relay failures across multiple 802.1Q VLANs using standard Cisco IOS verification commands (`show ip dhcp binding`, `show ip dhcp pool`, `show ip route`, `show ip interface`).
- Understand the function and behavior of `ip helper-address` on router subinterfaces, converting broadcast DHCP Discover messages (`255.255.255.255`) into routed unicast messages destined for a central DHCP server.
- Identify and correct helper-address misconfigurations (missing helper address, incorrect target IP, or helper configured on the wrong interface).
- Identify and correct DHCP pool scope mismatches on the central DHCP server where `network` statements do not correspond to the subinterface subnet (`giaddr`) provided by the relay agent.
- Verify end-to-end lease acquisition, default gateway assignment, and DNS server distribution on remote VLAN client endpoints.

## 4. DHCP Server & Relay Specifications

### DHCP Server Pools on `R1-HQ`:
```cisco
ip dhcp excluded-address 10.0.0.1 10.0.0.10
ip dhcp excluded-address 192.168.10.1 192.168.10.10
ip dhcp excluded-address 192.168.20.1 192.168.20.10

ip dhcp pool POOL_VLAN10
 network 192.168.10.0 255.255.255.0
 default-router 192.168.10.1
 dns-server 10.0.0.1
 domain-name enterprise.local

ip dhcp pool POOL_VLAN20
 network 192.168.20.0 255.255.255.0
 default-router 192.168.20.1
 dns-server 10.0.0.1
 domain-name enterprise.local
```

### Routing:
- `R1-HQ`: `ip route 192.168.0.0 255.255.0.0 10.0.0.2` (return path to branch subnets)
- `R2-Branch`: `ip route 0.0.0.0 0.0.0.0 10.0.0.1` (default route to central server)

### Relay Configuration on `R2-Branch` (Completed):
```cisco
interface GigabitEthernet0/1.10
 encapsulation dot1Q 10
 ip address 192.168.10.1 255.255.255.0
 ip helper-address 10.0.0.1

interface GigabitEthernet0/1.20
 encapsulation dot1Q 20
 ip address 192.168.20.1 255.255.255.0
 ip helper-address 10.0.0.1
```

## 5. Fault Injection (Starter State)

1. **Fault 1 (VLAN 10 - Wrong Helper Address):**
   - On `R2-Branch` subinterface `GigabitEthernet0/1.10`, `ip helper-address 10.0.0.5` is configured instead of `10.0.0.1`.
   - Symptom: `PC-VLAN10` broadcasts DHCP Discover, `R2-Branch` relays to unreachable `10.0.0.5`. `PC-VLAN10` receives no offer and falls back to APIPA (or 0.0.0.0).
   - Fix: `no ip helper-address 10.0.0.5`, followed by `ip helper-address 10.0.0.1`.

2. **Fault 2 (VLAN 20 - Server Pool Scope Mismatch):**
   - On `R1-HQ`, the pool for VLAN 20 is erroneously defined as:
     ```cisco
     ip dhcp pool POOL_VLAN20
      network 192.168.200.0 255.255.255.0
      default-router 192.168.200.1
     ```
   - Symptom: `R2-Branch` properly relays DHCP Discovers with `giaddr = 192.168.20.1`, but `R1-HQ` has no matching pool for `192.168.20.0/24`, so it silently ignores requests.
   - Fix: On `R1-HQ`, reconfigure pool `POOL_VLAN20` with `network 192.168.20.0 255.255.255.0` and `default-router 192.168.20.1`.
