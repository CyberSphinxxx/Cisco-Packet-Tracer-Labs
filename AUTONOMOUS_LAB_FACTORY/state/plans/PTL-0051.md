## 2. Learning Objectives & Curriculum Outcomes
- Architect and secure a three-legged perimeter firewall topology featuring Inside LAN, Demilitarized Zone (DMZ), and Outside WAN boundaries.
- Design, deploy, and verify named extended IPv4 Access Control Lists (`OUTSIDE_TO_DMZ` and `DMZ_POLICY`) enforcing the principle of least privilege.
- Permit external clients to access legitimate public DMZ services (HTTP TCP 80, HTTPS TCP 443, ICMP echo) while strictly blocking unauthorized external access to private internal corporate subnets.
- Enforce strict DMZ-to-Internal isolation, allowing only controlled database query traffic (TCP 3306) from the DMZ application server to the internal database host, while preventing compromised DMZ nodes from pivoting into corporate workstations.
- Diagnose and remediate perimeter security defects including ACL directionality errors, rule ordering/shadowing flaws, and missing interface filter bindings.

## 4. Access Control List Policy Specification

### Inbound Edge Filter (`OUTSIDE_TO_DMZ`) on Gi0/0/1:
Applied: `interface GigabitEthernet0/0/1` -> `ip access-group OUTSIDE_TO_DMZ in`
```cisco
ip access-list extended OUTSIDE_TO_DMZ
 remark Permit Outside Clients to DMZ Web Server HTTP
 permit tcp any host 172.16.2.10 eq www
 remark Permit Outside Clients to DMZ Web Server HTTPS
 permit tcp any host 172.16.2.10 eq 443
 remark Permit Diagnostic Ping to DMZ Web Server
 permit icmp any host 172.16.2.10 echo
 remark Explicitly Deny Outside Traffic to Internal Corporate Network
 deny ip any 192.168.1.0 0.0.0.255
 remark Deny All Other Traffic
 deny ip any any
```

### Inbound DMZ Filter (`DMZ_POLICY`) on Gi0/0/2:
Applied: `interface GigabitEthernet0/0/2` -> `ip access-group DMZ_POLICY in`
```cisco
ip access-list extended DMZ_POLICY
 remark Permit DMZ Web to Query Internal Database on MySQL TCP 3306
 permit tcp host 172.16.2.10 host 192.168.1.50 eq 3306
 remark Permit DMZ Nodes to Ping Local Gateway
 permit icmp 172.16.2.0 0.0.0.255 host 172.16.2.1 echo
 remark Deny DMZ Subnet from Accessing Internal Corporate Network
 deny ip 172.16.2.0 0.0.0.255 192.168.1.0 0.0.0.255
 remark Permit DMZ Nodes to Reach External Internet Services
 permit ip host 172.16.2.10 any
 remark Deny All Other Traffic
 deny ip any any
```
