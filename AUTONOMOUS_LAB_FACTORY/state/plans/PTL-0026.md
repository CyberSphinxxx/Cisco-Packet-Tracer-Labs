## 1. Pedagogical Scope & Objectives

IPv6 eliminates the absolute dependence on stateful DHCP servers for client host addressing through **Stateless Address Autoconfiguration (SLAAC)** defined in IETF RFC 4862. SLAAC relies on the **IPv6 Neighbor Discovery Protocol (NDP)** (RFC 4861), which uses ICMPv6 messages to replace ARP and enable autonomous host configuration.

In this laboratory, students will:
1. Enable IPv6 routing on Cisco IOS (`ipv6 unicast-routing`) to initiate periodic ICMPv6 Router Advertisements (RAs, type 134) on the local LAN.
2. Configure static IPv6 Global Unicast (`2001:db8:acad:1::1/64`) and standardized Link-Local (`fe80::1`) addresses on the gateway router.
3. Configure client PCs (`PC-A` and `PC-B`) to use SLAAC autoconfiguration, observing how each host dynamically generates a 64-bit Interface Identifier (using EUI-64 or randomized tokens) and binds to the advertised `/64` prefix.
4. Verify end-to-end IPv6 reachability across hosts and the router gateway using ICMPv6 echo requests (`ping`).
5. Inspect the IPv6 Neighbor Discovery cache on Cisco IOS using `show ipv6 neighbors`, analyzing MAC-to-IPv6 bindings, link-layer resolution, and reachability states (`REACH`, `STALE`, `INCMP`).
6. Test negative scenarios:
   - Disabling `ipv6 unicast-routing` to observe the failure of Router Advertisements and host autoconfiguration.
   - Pinging an unassigned IPv6 address on the subnet to trigger unresolved Neighbor Solicitations (NS) resulting in `INCMP` state.

## 4. Verification Test Matrix

- **POS-01 (Router RA & Prefix Advertisement):** Verify `R1` has `ipv6 unicast-routing` enabled and `show ipv6 interface GigabitEthernet0/0/0` confirms periodic ND router advertisements with prefix `2001:DB8:ACAD:1::/64`.
- **POS-02 (Host SLAAC Autoconfiguration):** Verify `PC-A` and `PC-B` autoconfigure a valid GUA matching `2001:db8:acad:1:.../64` and set default gateway to `fe80::1`.
- **POS-03 (Host-to-Gateway Reachability):** Ping `2001:db8:acad:1::1` from `PC-A` and `PC-B` with 100% success rate.
- **POS-04 (Host-to-Host LAN Reachability):** Ping between `PC-A` and `PC-B` GUAs over IPv6 with 100% success rate.
- **POS-05 (IPv6 Neighbor Discovery Cache Inspection):** On `R1`, `show ipv6 neighbors` reveals valid entries for `PC-A` and `PC-B` in `REACH` state with resolved MAC addresses.
- **NEG-01 (Missing RA Routing Disabled):** Disable `ipv6 unicast-routing` on `R1`. Verify `R1` ceases RA transmissions and newly connecting hosts fail SLAAC configuration.
- **NEG-02 (Unresolved Neighbor Solicitation):** Ping non-existent host `2001:db8:acad:1::999` from `R1`. Verify `show ipv6 neighbors` records `INCMP` (Incomplete) state before aging out.
- **Reload Verification:** Verify clean baseline in `starter.pkt` and fully configured SLAAC environment in `completed.pkt`.
