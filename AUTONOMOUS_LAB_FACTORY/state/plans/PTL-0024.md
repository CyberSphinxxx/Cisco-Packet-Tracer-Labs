- **Lab ID:** PTL-0024

- **Category:** network-fundamentals
- **Difficulty:** beginner
- **Estimated Duration:** 45 minutes

## 2. Educational & Technical Objectives
- **Scope:** Discover network topology, verify physical interconnects, and audit device capabilities using Cisco Discovery Protocol (CDP) commands, followed by security hardening on edge interfaces.
- **Target Audience:** CCNA / Network Engineers learning Layer 2 discovery, physical cabling verification, and device reconnaissance.
- **Acceptance Criteria:**
  - Observed neighbor IDs, capabilities, and port mappings match physical topology exactly.
  - Comprehensive inspection of TLV fields using `show cdp neighbors detail`.
  - Edge interface hardening demonstrated by disabling CDP on end-user access ports (`no cdp enable`).
  - Protocol state verification demonstrated by testing `no cdp run` and re-enabling.

## 3. Topology & IP Addressing Plan
### 3.1 Devices & Interfaces
- **R1** (Cisco ISR 4321):
  - `GigabitEthernet0/0/0`: `192.168.1.1/24` (Connects to S1 `Gig0/1`)
- **S1** (Catalyst 2960-24TT - Distribution Switch):
  - `GigabitEthernet0/1`: Connects to `R1` `Gi0/0/0`
  - `FastEthernet0/1`: Connects to `S2` `FastEthernet0/1`
  - `FastEthernet0/2`: Connects to `S3` `FastEthernet0/1`

- **S2** (Catalyst 2960-24TT - Access Switch 1):
  - `FastEthernet0/1`: Connects to `S1` `FastEthernet0/1`
  - `FastEthernet0/10`: Connects to `PC-Admin` `FastEthernet0`
  - `Vlan1`: `192.168.1.3/24`
- **S3** (Catalyst 2960-24TT - Access Switch 2):
  - `FastEthernet0/1`: Connects to `S1` `FastEthernet0/2`

- **PC-Admin** (PC-PT):
  - `FastEthernet0`: `192.168.1.50/24`, Gateway: `192.168.1.1`

## 4. Configuration Steps
### 4.1 Starter State
- Baseline hostnames, IP addresses, and default gateways on all devices.
- CDP active by default on all interfaces.
- End-user port S2 Fa0/10 has CDP enabled (information disclosure risk).

### 4.2 Completed State
- On S2:
  - `interface FastEthernet0/10`
  - `no cdp enable`
- Interface and global timer audits verified.

## 5. Verification Matrix
- **POS-01:** Multi-Neighbor Discovery on S1 (`show cdp neighbors` lists R1, S2, and S3).
- **POS-02:** Detailed TLV Inspection on R1 (`show cdp neighbors detail` reveals platform, version, IP address).
- **POS-03:** Specific Entry Query (`show cdp entry S1`).
- **POS-04:** Protocol Timers & Interface Audit (`show cdp interface`).
- **NEG-01:** Interface-Level Security Hardening (`no cdp enable` on S2 Fa0/10 stops advertisements).
- **NEG-02:** Global Protocol Disabling (`no cdp run` clears neighbor table and verifies `CDP is not enabled`).
- **Reload Proof:** Starter and Completed `.pkt` files reload cleanly without loss of topology or configurations.
