# PTL-0021 — Plan: Static NAT and Inside Server Publishing

- **Candidate task and original educational distinction:** Implement Static Network Address Translation (Static NAT) on an enterprise Cisco ISR 4321 edge router to publish an internal private web server (`192.168.10.80/24`) to an external simulated public IP address (`203.0.113.5/29`). Distinct from PTL-0020 (Dynamic PAT), which is outbound-initiated and multiplexed, Static NAT provides permanent, bidirectional one-to-one address mapping allowing external hosts to initiate inbound connections to published services while maintaining internal host isolation for unmapped clients (`PC-Internal`).
- **Prerequisites and canonical existing examples checked:** `PTL-0020` (IPv4 Dynamic PAT at the Edge) completed and reviewed. Canonical existing lab `labs/network-services/ipv4-dynamic-pat-at-the-edge` and `dhcp-server-and-relay` reviewed.
- **Packet Tracer version, real available device models/IOS:** Cisco Packet Tracer 9.0.1.0038. Router model: `ISR4321` (IOS-XE 16.6+), Switch model: `Catalyst 2960-24TT`, End devices: `PC-PT` (PC-Internal, PC-External) and `Server-PT` (Svr-Internal).
- **Required command/GUI support probe and actual result:** Probed Cisco ISR 4321 in live simulator: `ip nat inside source static 192.168.10.80 203.0.113.5`, `ip nat inside`, `ip nat outside`, and `show ip nat translations`. Confirmed permanent static translation entry creation and execution.
