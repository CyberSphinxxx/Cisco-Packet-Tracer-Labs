# Implementation Plan: PTL-0054 — Dual-Stack IPv4 and IPv6 Branch Network

## Lab Overview
- **Lab ID:** PTL-0054
- **Title:** Dual-Stack IPv4 and IPv6 Branch Network
- **Category:** routing
- **Difficulty:** advanced
- **Slug:** dual-stack-ipv4-and-ipv6-branch-network
- **Estimated Time:** 75 minutes
- **Prerequisites:** PTL-0027 (IPv6 Static and Default Routing Troubleshooting), PTL-0001 (Dual-Stack Static Routing)

## Learning Objectives
1. Design and configure dual-stack IPv4 and IPv6 addressing across core hub and branch router interfaces.
2. Implement dual-stack static routes and default routes for end-to-end multi-branch communication.
3. Validate full IPv4 and IPv6 reachability across dual-stack hosts in separate branch networks.
4. Diagnose and resolve intentional routing faults (incorrect next-hop IP, missing IPv6 default route).
5. Audit routing tables and neighbor discovery caches to ensure deterministic dual-stack path selection.

## IP Addressing Plan
- Branch-1 LAN: `192.168.10.0/24`, `2001:db8:acad:10::/64`
  - Branch-1-R1 Gi0/0: `192.168.10.1/24`, `2001:db8:acad:10::1/64`, LL: `fe80::1`
  - PC-BR1 Fa0: `192.168.10.10/24` (GW: `192.168.10.1`), `2001:db8:acad:10::10/64` (GW: `2001:db8:acad:10::1`)
- WAN 1 (Branch 1 <-> HQ): `10.1.12.0/30`, `2001:db8:acad:12::/64`
  - Branch-1-R1 Gi0/1: `10.1.12.1/30`, `2001:db8:acad:12::1/64`
  - HQ-R2 Gi0/1: `10.1.12.2/30`, `2001:db8:acad:12::2/64`
- HQ Core Loopback0: `172.16.1.1/24`, `2001:db8:acad:100::1/64`
- WAN 2 (HQ <-> Branch 2): `10.1.23.0/30`, `2001:db8:acad:23::/64`
  - HQ-R2 Gi0/2: `10.1.23.2/30`, `2001:db8:acad:23::2/64`
  - Branch-2-R3 Gi0/2: `10.1.23.3/30`, `2001:db8:acad:23::3/64`
- Branch-2 LAN: `192.168.20.0/24`, `2001:db8:acad:20::/64`
  - Branch-2-R3 Gi0/0: `192.168.20.1/24`, `2001:db8:acad:20::1/64`, LL: `fe80::3`
  - PC-BR2 Fa0: `192.168.20.10/24` (GW: `192.168.20.1`), `2001:db8:acad:20::10/64` (GW: `2001:db8:acad:20::1`)

## Verification Strategy
- **POS-01:** `PC-BR1` pings `PC-BR2` over IPv4 (`192.168.20.10`) with 0% loss.
- **POS-02:** `PC-BR1` pings `PC-BR2` over IPv6 (`2001:db8:acad:20::10`) with 0% loss.
- **POS-03:** `PC-BR2` pings `HQ-R2` Loopback0 IPv4 (`172.16.1.1`) with 0% loss.
- **POS-04:** `PC-BR2` pings `HQ-R2` Loopback0 IPv6 (`2001:db8:acad:100::1`) with 0% loss.
- **POS-05:** `ipv6 unicast-routing` enabled and routing tables active on `Branch-1-R1`, `HQ-R2`, and `Branch-2-R3`.
- **NEG-01:** Starter `Branch-2-R3` lacks IPv6 default route to `HQ-R2`, dropping `PC-BR1` -> `PC-BR2` IPv6 traffic (100% loss).
- **NEG-02:** Starter `Branch-1-R1` has incorrect next-hop (`10.1.12.5`) on default IPv4 static route, dropping IPv4 traffic to HQ and Branch 2.
