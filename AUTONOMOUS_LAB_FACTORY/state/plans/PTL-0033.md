# Lab Design Plan: PTL-0033 - Stateful DHCPv6 Address Assignment

## 1. Overview and Rationale
- **Lab ID:** PTL-0033
- **Slug:** `stateful-dhcpv6-address-assignment`
- **Category:** `network-services`
- **Difficulty:** Advanced
- **Estimated Minutes:** 60
- **Curriculum Objective:** Implement and verify Stateful DHCPv6 address assignment and router advertisements in an enterprise dual-router IPv6 environment. Learners configure a Cisco 4321 router as a stateful DHCPv6 server supplying IPv6 global unicast addresses (GUA), DNS server recursive resolution addresses, and domain search lists. Learners adjust ICMPv6 Router Advertisement flags (`managed-config-flag` and `no-autoconfig`) to instruct Windows/Cisco hosts to seek stateful leases, inspect client lease bindings, and verify routed end-to-end IPv6 connectivity across network boundaries.

## 2. Topology and IPv6 Addressing Plan
- **Topology:**
  - `DHCP-R1` (Cisco 4321 ISR, x: 240, y: 180) - Stateful DHCPv6 Server & LAN 1 Gateway
  - `Core-R2` (Cisco 4321 ISR, x: 560, y: 180) - Remote Core Router & LAN 2 Gateway
  - `Switch-S1` (Catalyst 2960-24TT, x: 240, y: 320) - LAN 1 Access Switch
  - `Switch-S2` (Catalyst 2960-24TT, x: 560, y: 320) - LAN 2 Access Switch
  - `PC1` (PC-PT, x: 160, y: 450) - LAN 1 Stateful DHCPv6 Client A
  - `PC2` (PC-PT, x: 320, y: 450) - LAN 1 Stateful DHCPv6 Client B
  - `Server-Remote` (Server-PT, x: 560, y: 450) - LAN 2 Remote Enterprise Server
- **Addressing Plan:**
  - **Inter-Router Transit Link (`DHCP-R1` Gi0/0/0 <-> `Core-R2` Gi0/0/0):**
    - Subnet: `2001:DB8:ACAD:A::/64`
    - `DHCP-R1` Gi0/0/0: `2001:DB8:ACAD:A::1/64`, Link-Local: `FE80::1`
    - `Core-R2` Gi0/0/0: `2001:DB8:ACAD:A::2/64`, Link-Local: `FE80::2`
  - **LAN 1 Subnet (`DHCP-R1` Gi0/0/1 <-> `Switch-S1` Fa0/1):**
    - Subnet: `2001:DB8:ACAD:1::/64`
    - `DHCP-R1` Gi0/0/1: `2001:DB8:ACAD:1::1/64`, Link-Local: `FE80::1`
    - `Switch-S1` VLAN 1: Management IP `2001:DB8:ACAD:1::5/64`
    - DHCPv6 Pool: `IPV6-STATEFUL-LAN1`
      - Leased Address Prefix: `2001:DB8:ACAD:1::/64`
      - Recursive DNS Server: `2001:4860:4860::8888`
      - Domain Name: `cisco.lab`
    - `PC1`: DHCPv6 Client (dynamically leases GUA in `2001:DB8:ACAD:1::/64`, Gateway: `FE80::1`)
    - `PC2`: DHCPv6 Client (dynamically leases GUA in `2001:DB8:ACAD:1::/64`, Gateway: `FE80::1`)
  - **LAN 2 Subnet (`Core-R2` Gi0/0/1 <-> `Switch-S2` Fa0/1):**
    - Subnet: `2001:DB8:ACAD:2::/64`
    - `Core-R2` Gi0/0/1: `2001:DB8:ACAD:2::1/64`, Link-Local: `FE80::2`
    - `Switch-S2` VLAN 1: Management IP `2001:DB8:ACAD:2::5/64`
    - `Server-Remote`: `2001:DB8:ACAD:2::100/64`, Gateway: `2001:DB8:ACAD:2::1`

## 3. Routing Architecture
- IPv6 Unicast Routing enabled globally on both routers (`ipv6 unicast-routing`).
- Static IPv6 Routes:
  - `DHCP-R1`: `ipv6 route 2001:DB8:ACAD:2::/64 2001:DB8:ACAD:A::2`
  - `Core-R2`: `ipv6 route 2001:DB8:ACAD:1::/64 2001:DB8:ACAD:A::1`

## 4. Starter vs. Completed States
- **Starter State (`starter.pkt`):**
  - Physical topology cabled, link lights active.
  - Basic IPv6 routing and transit interfaces configured on `DHCP-R1` and `Core-R2`.
  - `Server-Remote` configured with static IPv6 address and default gateway.
  - `PC1` and `PC2` configured to use DHCP for IPv6 address acquisition.
  - Stateful DHCPv6 pool and router advertisement M-flag are omitted from `DHCP-R1`.
  - NEG-01: PC1 and PC2 have no Global Unicast IPv6 addresses assigned.
  - NEG-02: `DHCP-R1` has no active DHCPv6 bindings.
- **Completed State (`completed.pkt`):**
  - `DHCP-R1` configured with stateful DHCPv6 pool `IPV6-STATEFUL-LAN1`.
  - `DHCP-R1` Gi0/0/1 configured with `ipv6 dhcp server IPV6-STATEFUL-LAN1`, `ipv6 nd managed-config-flag`, and `ipv6 nd prefix 2001:DB8:ACAD:1::/64 no-autoconfig`.
  - POS-01: PC1 obtains Global Unicast IPv6 address in `2001:DB8:ACAD:1::/64`.
  - POS-02: PC2 obtains Global Unicast IPv6 address in `2001:DB8:ACAD:1::/64`.
  - POS-03: PC1 obtains DNS server `2001:4860:4860::8888` and domain `cisco.lab`.
  - POS-04: `show ipv6 dhcp pool` on `DHCP-R1` confirms active clients >= 2.
  - POS-05: `show ipv6 dhcp binding` on `DHCP-R1` shows DUID and IPv6 lease bindings for clients.
  - POS-06: PC1 successfully pings `Server-Remote` (`2001:DB8:ACAD:2::100`).
  - POS-07: PC2 successfully pings `Server-Remote` (`2001:DB8:ACAD:2::100`).
