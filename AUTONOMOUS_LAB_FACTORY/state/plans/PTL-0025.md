# Lab Implementation Plan: PTL-0025 TFTP Configuration Backup and Restore

## 1. Metadata & Identification
- **Lab ID:** PTL-0025
- **Title:** TFTP Configuration Backup and Restore
- **Category:** network-services
- **Difficulty:** intermediate
- **Estimated Duration:** 60 minutes
- **Canonical Directory:** `labs/network-services/tftp-configuration-backup-and-restore`
- **Slug:** `tftp-configuration-backup-and-restore`

## 2. Educational & Technical Objectives
- **Scope:** Back up Cisco router configuration to an internal TFTP server, simulate an administrative disaster / configuration loss, and recover full system state from the remote backup.
- **Target Audience:** CCNA / Network Engineers learning network operations, disaster recovery, configuration management, and file transfer mechanisms.
- **Acceptance Criteria:**
  - Genuine backup configuration file (`R1-backup.cfg`) transferred over TFTP (UDP port 69) and stored on `TFTP-Server`.
  - Controlled disaster recovery tested: configuration alteration followed by successful restoration from TFTP.
  - Zero passwords, secrets, or sensitive hashes copied into public documentation.

## 3. Topology & IP Addressing Plan
### 3.1 Devices & Interfaces
- **R1** (Cisco ISR 4321):
  - `GigabitEthernet0/0/0`: `192.168.1.1/24` (Connects to S1 `Gig0/1`)
  - `Loopback0`: `10.25.1.1/24` (Simulated internal service interface)
- **S1** (Catalyst 2960-24TT):
  - `GigabitEthernet0/1`: Connects to `R1` `GigabitEthernet0/0/0`
  - `FastEthernet0/1`: Connects to `PC-Admin` `FastEthernet0`
  - `FastEthernet0/2`: Connects to `TFTP-Server` `FastEthernet0`
  - `Vlan1`: `192.168.1.2/24`
- **PC-Admin** (PC-PT):
  - `FastEthernet0`: `192.168.1.10/24`, Gateway: `192.168.1.1`
- **TFTP-Server** (Server-PT):
  - `FastEthernet0`: `192.168.1.250/24`, Gateway: `192.168.1.1`
  - Services: TFTP daemon active (UDP 69)

## 4. Configuration Steps
### 4.1 Starter State
- Baseline hostnames, IP addresses, banners on R1 and S1.
- TFTP server operational with standard factory image library.
- No backup file present for R1.

### 4.2 Completed State
- Active backup file `R1-backup.cfg` transferred to TFTP server.
- Successful restoration from TFTP to running configuration verified.
- Startup configuration synchronized on R1 and S1.

## 5. Verification Matrix
- **POS-01:** Baseline LAN IP Reachability (PC-Admin and R1 can reach TFTP-Server at 192.168.1.250).
- **POS-02:** TFTP Configuration Backup (`copy running-config tftp:` creates `R1-backup.cfg`).
- **POS-03:** TFTP Server File Storage Verification (inspect file existence on TFTP server).
- **POS-04:** Controlled Disaster & Recovery (`copy tftp: running-config` restores altered router state).
- **NEG-01:** Non-Existent File Transfer Fault (attempting to restore missing file produces error `Error opening tftp://...`).
- **NEG-02:** Unreachable TFTP Server Timeout (attempting backup to non-existent IP produces timeout / error).
- **Reload Proof:** Starter and Completed `.pkt` files reload cleanly without loss of topology or configurations.
