## Devices & Topology
- **R1:** Cisco ISR 4321 (Default Gateway & Authoritative DHCP Server)
  - Gi0/0/0 -> SW-1 Gi0/1
  - IP: 192.168.10.1 /24
  - DHCP Pool: CORP-POOL (192.168.10.0/24, GW 192.168.10.1, DNS 192.168.10.1, excluded .1-.9)
- **SW-1:** Cisco Catalyst 2960-24TT (Access Switch with DHCP Snooping & DAI)
  - VLAN 10: Corporate-Data
  - Gi0/1: Uplink to R1 (VLAN 10, DHCP Snooping Trusted & DAI Trusted)
  - Fa0/10: Client-1 (VLAN 10, Untrusted)
  - Fa0/11: Client-2 (VLAN 10, Untrusted)
  - Fa0/24: Attacker (VLAN 10, Untrusted)
- **Client-1:** PC-PT (DHCP Client, leases 192.168.10.10)
- **Client-2:** PC-PT (DHCP Client, leases 192.168.10.11)
- **Attacker:** PC-PT (Unauthorized host attempting static ARP injection with 192.168.10.50)

## Progression
1. **Starter State:**
   - DHCP Snooping enabled and active; legitimate clients hold DHCP leases.
   - Dynamic ARP Inspection (DAI) DISABLED.
   - Attacker on Fa0/24 configures static IP 192.168.10.50 and successfully communicates across VLAN 10 because standard Layer 2 switches do not validate ARP against the DHCP snooping database.
   - Demonstrates the Layer 2 security gap when DAI is omitted.
2. **Completed State:**
   - Enable DAI globally for VLAN 10: `ip arp inspection vlan 10`.
   - Enable additional ARP header validation: `ip arp inspection validate src-mac dst-mac ip`.
   - Designate uplink port Gi0/1 as trusted: `interface GigabitEthernet0/1`, `ip arp inspection trust`.
   - Access ports Fa0/10, Fa0/11, Fa0/24 remain untrusted by default.
   - Legitimate clients (Client-1, Client-2) communicate normally as their ARP packets match dynamic entries in `show ip dhcp snooping binding`.
   - Attacker's static / spoofed ARP packets on untrusted port Fa0/24 are intercepted and dropped by DAI, preventing network access and ARP cache poisoning.

## Verification Matrix
- **POS-01:** R1 interface Gi0/0/0 up/up and DHCP pool CORP-POOL active
- **POS-02:** SW-1 DHCP snooping operational status (enabled globally, VLAN 10, Option 82 disabled, Gi0/1 trusted)
- **POS-03:** SW-1 DAI operational status (`show ip arp inspection vlan 10` enabled/active, validation active)
- **POS-04:** SW-1 Gi0/1 interface trust verification (`show ip arp inspection interfaces GigabitEthernet0/1` -> Trusted)
- **POS-05:** Client-1 and Client-2 dynamic lease verification (`192.168.10.10` and `192.168.10.11`) and active snooping bindings
- **POS-06:** Client-1 end-to-end reachability to gateway (`192.168.10.1`) and Client-2 (`192.168.10.11`) with 4/4 echo replies
- **POS-07:** SW-1 DAI verification outputs (`show ip arp inspection` and `show ip arp inspection interfaces`)
- **NEG-01:** Starter state: Attacker unauthorized static ARP succeeds without DAI
- **NEG-02:** Completed state: Attacker unauthorized ARP / ping is dropped by DAI (100% packet loss)
