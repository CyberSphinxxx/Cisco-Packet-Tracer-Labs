## 1. Pedagogical Scope & Objectives

In enterprise hub-and-spoke and multi-branch architectures, IPv6 static and default routing provides deterministic, lightweight path selection between remote offices and central data centers without dynamic protocol overhead. However, subtle configuration errors—such as omitting `ipv6 unicast-routing`, typographic errors in 128-bit next-hop IPv6 addresses, or omitting reverse return routes—can disrupt connectivity and create routing black holes.

In this laboratory, students will:
1. Analyze a multi-router transit topology consisting of two branch office edge routers (`R1` and `R3`) interconnected through a central corporate hub router (`R2`).
2. Diagnose and resolve common IPv6 routing failures:
   - Missing default route (`ipv6 route ::/0 <next-hop>`) on edge routers.
   - Typographic errors in global unicast next-hop addresses.
   - Missing global unicast routing enablement (`ipv6 unicast-routing`) on forwarding routers.
3. Configure recursive and next-hop IPv6 static routes on the hub router to reach stub LAN subnets and loopbacks.
4. Verify end-to-end IPv6 reachability using ICMPv6 echo requests (`ping`) and path tracing (`traceroute`).
5. Inspect the IPv6 routing table (`show ipv6 route`, `show ipv6 route static`) to verify route installation, administrative distance (AD=1), and metric calculation.
6. Verify failure behavior by negating routes and observing traffic interruption.

## 4. Verification Test Matrix

- **POS-01 (WAN Pings & Direct Connectivity):** Pings between `R1` and `R2` (`2001:db8:acad:12::2`) and between `R2` and `R3` (`2001:db8:acad:23::3`) succeed with 100% rate.
- **POS-02 (Static Route Table Installation):** `show ipv6 route static` on `R1`, `R2`, and `R3` verifies installed `S ::/0` default routes and `S 2001:DB8:ACAD:.../64` specific branch routes.
- **POS-03 (Host-to-Hub Reachability):** `ping 2001:db8:acad:202::1` (R2 Central Loopback) from `PC-1` and `PC-2` succeeds with 100% rate.
- **POS-04 (End-to-End Inter-Branch Host Reachability):** `ping 2001:db8:acad:3::10` from `PC-1` succeeds with 100% rate.
- **POS-05 (Traceroute Hop Path Verification):** `tracert 2001:db8:acad:3::10` from `PC-1` traverses `R1` (`2001:db8:acad:1::1`) -> `R2` (`2001:db8:acad:12::2`) -> `R3` (`2001:db8:acad:23::3`) -> `PC-2`.
- **NEG-01 (Missing Return Route Drop):** Remove `R1` LAN static route from `R2` (`no ipv6 route 2001:db8:acad:1::/64 2001:db8:acad:12::1`). Ping from `PC-1` to `R2` fails; traffic drops due to missing reverse path.
- **NEG-02 (Disabled Global Forwarding):** Issue `no ipv6 unicast-routing` on `R2`. Verify `R2` stops forwarding transit packets between `PC-1` and `PC-2`.
- **Reload Verification:** Verify clean baseline in `starter.pkt` and fully converged network in `completed.pkt`.
