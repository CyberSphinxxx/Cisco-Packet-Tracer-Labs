## Problem Statement & Educational Value
In redundant switched networks, the Spanning Tree Protocol (STP / RSTP) eliminates Layer 2 bridging loops by electing a single Root Bridge and transitioning redundant loop-forming ports into an Alternate/Blocking state. If bridge priorities are unmanaged or misconfigured, an edge access switch can inadvertently win the root bridge election due to having the lowest default MAC address or an unintended priority setting.
When an access switch becomes the root bridge:
1. High-capacity core/distribution inter-switch links are placed into an Alternate Blocking state (`Altn BLK`).
2. All inter-switch campus traffic is forced to traverse low-capacity access switches, causing congestion, elevated latency, and severe performance degradation.
3. Spanning tree topology becomes fragile; access switch reboots trigger global topology change notifications (TCNs) and CAM table flushes.

In this lab, learners investigate a redundant triangle topology where an access switch (`SW-3`) has improperly seized the root bridge role, causing the high-speed distribution trunk (`SW-1` <-> `SW-2`) to block. Learners diagnose root IDs and port states using `show spanning-tree`, determine path costs, calculate root port elections, remediate bridge priorities deterministically (`SW-1` priority 4096, `SW-2` priority 8192, `SW-3` priority 32768), and verify that blocked ports shift to non-critical access uplinks while preserving full loop-free reachability.

## Topology Design
- **Switches:**
  - `SW-1` (Catalyst 2960-24TT): Distribution Switch 1 (Target: Primary Root Bridge, Priority 4096)
  - `SW-2` (Catalyst 2960-24TT): Distribution Switch 2 (Target: Secondary Root Bridge, Priority 8192)
  - `SW-3` (Catalyst 2960-24TT): Access Switch (Target: Access Bridge, Priority 32768)
- **Endpoints:**
  - `PC-1` (PC-PT): Connected to `SW-1` `Fa0/10` (`192.168.1.10/24`)
  - `PC-2` (PC-PT): Connected to `SW-3` `Fa0/10` (`192.168.1.20/24`)
  - `Server-1` (Server-PT): Connected to `SW-2` `Fa0/10` (`192.168.1.100/24`)
- **Cabling Matrix:**
  - `SW-1 Gi0/1` <-> `SW-2 Gi0/1` (Copper Crossover, Core Trunk Link)
  - `SW-1 Fa0/1` <-> `SW-3 Fa0/1` (Copper Crossover / Straight, Access Uplink 1)
  - `SW-2 Fa0/1` <-> `SW-3 Fa0/2` (Copper Crossover / Straight, Access Uplink 2)
  - `SW-1 Fa0/10` <-> `PC-1 Fa0` (Copper Straight-Through)
  - `SW-3 Fa0/10` <-> `PC-2 Fa0` (Copper Straight-Through)
  - `SW-2 Fa0/10` <-> `Server-1 Fa0` (Copper Straight-Through)

## Spanning Tree Configuration Matrix
- **STP Mode:** Rapid-PVST (`spanning-tree mode rapid-pvst`)
- **Completed State:**
  - `SW-1`: `spanning-tree vlan 1 priority 4096` -> ROOT BRIDGE (`This bridge is the root`)
    - `Gi0/1`: Role `Desg`, State `FWD`
    - `Fa0/1`: Role `Desg`, State `FWD`
    - `Fa0/10`: Role `Desg`, State `FWD` (PortFast enabled)
  - `SW-2`: `spanning-tree vlan 1 priority 8192` -> SECONDARY ROOT
    - `Gi0/1`: Role `Root`, State `FWD` (Direct path to root)
    - `Fa0/1`: Role `Desg`, State `FWD`
    - `Fa0/10`: Role `Desg`, State `FWD` (PortFast enabled)
  - `SW-3`: `spanning-tree vlan 1 priority 32768` (Default)
    - `Fa0/1`: Role `Root`, State `FWD` (Path to SW-1 root)
    - `Fa0/2`: Role `Altn`, State `BLK` (Alternate blocked port!)
    - `Fa0/10`: Role `Desg`, State `FWD` (PortFast enabled)
- **Faulted Starter State:**
  - `SW-3`: `spanning-tree vlan 1 priority 4096` -> INADVERTENT ROOT BRIDGE!
  - `SW-1`: `spanning-tree vlan 1 priority 32768`
  - `SW-2`: `spanning-tree vlan 1 priority 32768`
  - Inverted Topology Symptoms:
    - `SW-3` is root (`This bridge is the root`).
    - `SW-1` port `Fa0/1` is Root Port.
    - `SW-2` port `Fa0/1` is Root Port.
    - Core distribution trunk `SW-2 Gi0/1` is forced into `Altn BLK`, blocking the high-capacity core link!

## Verification Points
- **POS-01:** Root Bridge Election: `SW-1` is root bridge for VLAN 1 (`This bridge is the root`, Root ID matches Bridge ID `4097`).
- **POS-02:** Secondary Root Priority: `SW-2` Bridge priority is `8193` (Priority 8192 + Sys-id-ext 1).
- **POS-03:** Core Trunk Unblocked: `SW-1 Gi0/1` is `Desg FWD` and `SW-2 Gi0/1` is `Root FWD`.
- **POS-04:** Alternate Blocked Port on Access Uplink: `SW-3 Fa0/2` is `Altn BLK`.
- **POS-05:** End-to-End Reachability: `PC-1` -> `Server-1` (`192.168.1.100`) succeeds (4/4 echo replies, 0% loss).
- **POS-06:** Access Host Reachability: `PC-2` -> `Server-1` (`192.168.1.100`) succeeds (4/4 echo replies, 0% loss).
- **NEG-01:** Starter State Root Inversion Audit: In starter state, `SW-3` reports `This bridge is the root` with priority `4097`.
- **NEG-02:** Starter State Suboptimal Core Blocking Audit: In starter state, `SW-2 Gi0/1` or `SW-1 Gi0/1` is in `Altn BLK` state, blocking core distribution bandwidth.
