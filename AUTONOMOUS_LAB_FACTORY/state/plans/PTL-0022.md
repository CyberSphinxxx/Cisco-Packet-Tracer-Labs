---

## 2. Pedagogical Objectives
1. Explain the role of the Domain Name System (DNS) in resolving human-readable Fully Qualified Domain Names (FQDNs) to IPv4 addresses.
2. Differentiate between DNS resource record types: Address (A) records and Canonical Name (CNAME) aliases.
3. Configure and enable DNS server services on Cisco Packet Tracer Server-PT.
4. Configure DNS client settings on end workstations pointing to the authoritative internal DNS server.
5. Verify name resolution using `nslookup` and ICMP echo requests by hostname.
6. Verify HTTP web service retrieval over hostname URLs using the Packet Tracer Web Client.
7. Diagnose and remediate common DNS resolution failures including service disabled, wrong DNS server IP, and misspelled record entries.

## 4. Starter vs Completed Differentiation
- **Starter (`starter.pkt`):**
  - All cabling, switch VLANs, router interfaces, and endpoint IP configurations are complete.
  - Endpoints have DNS configured to `192.168.20.50`.
  - DNS Service on `DNS-Server` is DISABLED (`isEnabled() == false`) and database is empty.
  - Pings by IP address succeed; `nslookup` and HTTP requests by hostname fail.
- **Completed (`completed.pkt`):**
  - DNS Service on `DNS-Server` is ENABLED.
  - A and CNAME records populated and operational.
  - Full name resolution and web page delivery proven.

---

## 5. Verification Matrix
- **POS-01:** Subnet routing and direct IP connectivity (`PC-1` -> `192.168.20.80`).
- **POS-02:** A record lookup (`nslookup web.corp.local` returns `192.168.20.80`).
- **POS-03:** CNAME alias lookup (`nslookup www.corp.local` resolves to `web.corp.local`).
- **POS-04:** Second A record lookup (`nslookup portal.corp.local` returns `192.168.20.80`).
- **POS-05:** HTTP web page retrieval (`HttpClient.go("http://www.corp.local")`).
- **NEG-01:** Unregistered hostname resolution failure (`nslookup unknown.corp.local`).
- **NEG-02:** Fault injection (record deletion / corruption) and recovery.
- **REL-01/02:** Reopen verification for starter and completed files.
