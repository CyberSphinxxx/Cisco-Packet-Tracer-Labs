# Lab Implementation Plan: PTL-0029

**Lab ID:** `PTL-0029`  
**Lab Title:** OSPFv2 DR and BDR Elections  
**Category:** `routing`  
**Difficulty:** Intermediate  
**Estimated Time:** 60 minutes  
**Candidate Status:** Approved  

---

## 1. Educational Objectives & Scope
- Teach the role and mathematical motivation of Designated Routers (DR) and Backup Designated Routers (BDR) on multi-access broadcast networks.
- Configure OSPFv2 Single-Area 0 across a multi-access Ethernet switch segment with multiple routers.
- Analyze default election criteria (Router ID tie-breaking).
- Configure deterministic DR and BDR elections using interface priorities (`ip ospf priority <0-255>`).
- Demonstrate DROther role assignment using priority `0`.
- Verify neighbor adjacency states (`FULL/DR`, `FULL/BDR`, `FULL/DROTHER`, and `2-WAY/DROTHER`).
- Demonstrate non-preemptive election mechanics and failover behavior.

---

## 2. Device & Addressing Plan
- **Switch S1** (Catalyst 2960-24TT):
  - Multi-access Layer 2 broadcast domain connecting R1, R2, R3, and PC-1 on VLAN 1.
- **Router R1** (Cisco ISR 4321):
  - `Gi0/0/0`: `192.168.1.1/24`, OSPF Priority `255` (Target DR)
  - `Loopback0`: `10.1.1.1/24`, Router ID `1.1.1.1`
- **Router R2** (Cisco ISR 4321):
  - `Gi0/0/0`: `192.168.1.2/24`, OSPF Priority `100` (Target BDR)
  - `Loopback0`: `10.2.2.1/24`, Router ID `2.2.2.2`
- **Router R3** (Cisco ISR 4321):
  - `Gi0/0/0`: `192.168.1.3/24`, OSPF Priority `0` (Target DROther)
  - `Loopback0`: `10.3.3.1/24`, Router ID `3.3.3.3`
- **Host PC-1** (PC-PT):
  - `FastEthernet0`: `192.168.1.50/24`, Gateway `192.168.1.1`

## 3. Implementation Workflow
1. Clear canvas and construct topology (`R1`, `R2`, `R3`, `S1`, `PC-1`).
2. Cable all router `Gi0/0/0` ports and PC-1 `Fa0` to `S1`.
3. Provision starter state:
   - IP addresses configured.
   - OSPFv2 process 1 enabled on all routers in Area 0 with default priority 1.
   - Non-deterministic / default election state.
4. Capture `topology.png` and save `starter.pkt`.
5. Apply solution state:
   - Configure `ip ospf priority 255` on R1 Gi0/0/0.
   - Configure `ip ospf priority 100` on R2 Gi0/0/0.
   - Configure `ip ospf priority 0` on R3 Gi0/0/0.
   - Restart OSPF process (`clear ip ospf process`) to trigger deterministic election.
   - Save startup configurations.
6. Run verification matrix:
   - POS-01: Multi-access subnet pings.
   - POS-02: Neighbor states on R1 (`FULL/BDR`, `FULL/DROTHER`) and R3 (`FULL/DR`, `FULL/BDR`).
   - POS-03: Interface OSPF roles (`DR`, `BDR`, `DROTHER`) via `show ip ospf interface`.
   - POS-04: Route table propagation (`show ip route ospf`) and ping from PC-1 to all loopbacks.
   - NEG-01: Priority 0 exclusion test (R3 never participates).
   - NEG-02: Non-preemptive behavior test.
7. Save `completed.pkt`.
8. Export clean configs (`configs/R1.txt`, `configs/R2.txt`, `configs/R3.txt`, `configs/S1.txt`).
9. Author documentation (`metadata.json`, `README.md`, `verification.md`, `PTL-0029-SIMULATOR-RESULTS.md`).
10. Run all repository and site quality gates.
11. Commit locally and record completion in queue.
