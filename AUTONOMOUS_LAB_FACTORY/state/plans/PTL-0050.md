## 2. Learning Objectives & Curriculum Outcomes
- Enforce strict Layer 3 network security boundaries isolating an untrusted Guest subnet (`172.16.50.0/24`) from a sensitive Corporate intranet LAN (`192.168.10.0/24`).
- Design, author, and deploy a named extended IPv4 Access Control List (`GUEST_FILTER`) conforming to the principle of least privilege.
- Permit designated public services including DNS (UDP 53) and HTTP/HTTPS (TCP 80/443) to external servers (`203.0.113.53`) while blocking all internal corporate access.
- Correctly place access lists on the router interface closest to the traffic source (`GigabitEthernet0/0/2 in`) to optimize router processor resources and prevent unwanted traffic propagation.
- Diagnose and troubleshoot ACL directionality errors, rule shadowing, and interface application misplacements.

## 4. ACL Security Policy Matrix

Named Extended IPv4 ACL: `GUEST_FILTER`
Applied: `interface GigabitEthernet0/0/2` -> `ip access-group GUEST_FILTER in`

| Rule # | Action | Protocol | Source | Destination | Port / Details |
|---|---|---|---|---|---|
| 10 | `permit` | `udp` | `172.16.50.0 0.0.0.255` | `host 203.0.113.53` | `eq domain` (53) |
| 20 | `permit` | `tcp` | `172.16.50.0 0.0.0.255` | `host 203.0.113.53` | `eq www` (80) |
| 30 | `permit` | `tcp` | `172.16.50.0 0.0.0.255` | `host 203.0.113.53` | `eq 443` |
| 40 | `permit` | `icmp` | `172.16.50.0 0.0.0.255` | `host 172.16.50.1` | `echo` (Local GW Diagnostic) |
| 50 | `deny` | `ip` | `172.16.50.0 0.0.0.255` | `192.168.10.0 0.0.0.255` | Block all Corporate Subnet Access |
| 60 | `deny` | `ip` | `any` | `any` | Implicit / explicit deny remaining traffic |

## 5. Verification Matrix

### Positive Verification (Completed State)
- **POS-01:** `show ip access-lists GUEST_FILTER` on `R1-Edge` confirms all rules active with non-zero match counts.
- **POS-02:** `show ip interface GigabitEthernet0/0/2` verifies `Inbound access list is GUEST_FILTER`.
- **POS-03:** `Guest-Laptop` pings local default gateway `172.16.50.1` -> 4/4 echo replies (0% packet loss).
- **POS-04:** `Guest-Laptop` accesses public web service on `203.0.113.53` -> HTTP connection successful (port 80).
- **POS-05:** `Corp-PC` pings `Corp-Server` (`192.168.10.50`) -> 4/4 echo replies (0% packet loss).
- **POS-06:** `Corp-PC` pings `Public-DNS-Web` (`203.0.113.53`) -> 4/4 echo replies (0% packet loss).

### Negative Verification (Starter & Security Enforcement State)
- **NEG-01:** `Guest-Laptop` attempts ping to `Corp-PC` (`192.168.10.10`) -> 100% packet loss (`Destination host unreachable` / `Request timed out`).
- **NEG-02:** `Guest-Laptop` attempts ping to `Corp-Server` (`192.168.10.50`) -> 100% packet loss (`Destination host unreachable`).
- **NEG-03:** Starter state misdirection: ACL misapplied to Gi0/0/0 outbound, leaving Gi0/0/2 unfiltered.
