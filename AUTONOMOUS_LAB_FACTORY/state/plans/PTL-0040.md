## 2. Technical Scope & Learning Objectives
- **Scope:** Diagnose and resolve Layer 2 switchport port security faults across Cisco Catalyst access switches. Analyze stale sticky MAC address conflicts, recover interfaces latched in `err-disabled` (`Secure-shutdown`) state without disabling security, and reconfigure violation modes from silent drop (`protect`) to audit-compliant (`restrict`/`shutdown`).
- **Learning Objectives:**
  1. Diagnose port security violation symptoms and error-disabled port states using `show port-security interface` and `show interfaces status`.
  2. Resolve sticky MAC address collisions resulting from authorized workstation replacements and stale configuration entries.
  3. Execute the standard administrative recovery sequence (`shutdown` followed by `no shutdown`) to restore error-disabled switchports without removing port security controls.
  4. Evaluate differences in security posture and logging between `protect`, `restrict`, and `shutdown` violation modes.
  5. Verify end-to-end IP reachability for recovered legitimate endpoints while ensuring unauthorized devices trigger active security enforcement.

## 5. Fault Scenarios (Starter State)
1. **Fault 1 (Fa0/1):** Stale sticky MAC (`0000.1111.AAAA`) configured on `Fa0/1`. When `PC-1` transmitted, `Fa0/1` latched into `err-disabled` (`Secure-shutdown`). `PC-1` cannot reach the gateway.
2. **Fault 2 (Fa0/2):** Unauthorized laptop previously violated `Fa0/2`, latching the port into `err-disabled`. The unauthorized laptop was disconnected and legitimate `PC-2` reconnected, but the port remains `err-disabled`.
3. **Fault 3 (Fa0/3):** Port configured with violation mode `protect`. Security policy requires `restrict` so unauthorized traffic generates syslog messages and increments violation counters.

## 6. Remediation Procedures (Completed State)
1. **Remediation 1 (Fa0/1):**
   ```text
   SW-1(config)# interface FastEthernet0/1
   SW-1(config-if)# no switchport port-security mac-address sticky 0000.1111.AAAA
   SW-1(config-if)# shutdown
   SW-1(config-if)# no shutdown
   ```
   `PC-1` transmits, and its real MAC is learned dynamically as sticky.
2. **Remediation 2 (Fa0/2):**
   ```text
   SW-1(config)# interface FastEthernet0/2
   SW-1(config-if)# shutdown
   SW-1(config-if)# no shutdown
   ```
   Port clears `err-disabled` latch and returns to `Secure-up`.
3. **Remediation 3 (Fa0/3):**
   ```text
   SW-1(config)# interface FastEthernet0/3
   SW-1(config-if)# switchport port-security violation restrict
   ```
