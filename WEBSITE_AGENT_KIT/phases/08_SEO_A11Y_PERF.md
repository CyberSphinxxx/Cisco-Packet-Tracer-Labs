# Phase 08 — SEO, accessibility, polish and performance

**Outcome:** Fast, semantic, accessible site with reliable production metadata and mobile usability.

Tasks: site title/description from source metadata, canonical strategy configurable by owner-provided origin, sitemap/robots, OpenGraph images, breadcrumbs and justified structured data; do not invent production domain. Inspect page heading hierarchies, keyboard support, focus, alt text, reduced motion, 200% zoom and mobile tables. Audit external link safety, sanitized Markdown, font/image budgets, JS bundles, Lighthouse where available. Fix superficial UI friction and contrast issues.

**Gate:** no known critical accessibility failures or horizontal page overflow, SEO metadata valid for production config, no fake ratings/affiliation, performance measurements truthful, no extra JS needed for core content.
