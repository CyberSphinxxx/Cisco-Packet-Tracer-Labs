# Phase 03 — Responsive design foundation

**Outcome:** A distinctive, credible networking education visual system, not generic component-card wallpaper.

Tasks: design tokens, typography, color contrast, light/dark theme, SiteHeader/nav/search trigger, mobile nav, Footer, PageShell, breadcrumbs, skip link, lab/prose layouts, consistent buttons/icons/status. Implement useful home hero, first-lab CTA, category list and learning paths using source data. Mobile/desktop layouts actual rendering and keyboard checks. Use CSS rather than unnecessary SPA; if using Tailwind justify and pin version. Check 320px, 390px, 768px, 1024px, 1440px. Keep readable line length and prevent whole-page overflow.

**Gate:** home and shell usable without JS, nav and theme accessible, multiple real screenshots inspected if browser available, no dead controls, no fake metrics, source-driven data only.
