# PHASE 04 — Upgrade rights-cleared legacy lab guides

## Goal
Upgrade all publishable legacy labs to consistent, useful technical learning material.

## Actions
1. For each approved lab create/read `metadata.json` and canonical README using `07_LAB_AUTHORING.md` and template.
2. Explain basic concepts, objectives, requirements, device models/interface mapping, addressing table, step-by-step tasks, full CLI commands, verification, troubleshooting, references, downloadable file status.
3. Source research authoritative current command docs. Separate material originally taught by course from independent written explanation; never copy proprietary instructor texts.
4. Check each command and expected result. Log unknown Packet Tracer version or real output. Do not invent screenshots or `.pkt` binaries.
5. Include starter/complete download only if file really exists and rights allow distribution; otherwise offer original independent conceptual instructions and external reference.
6. Rate each upgraded lab with scoring rubric. Only mark reviewed/published when criteria met. Update index and progress after each batch of 1-3 labs.
7. Build beginner-friendly docs: `docs/getting-started.md`, `docs/installation.md` linking official Packet Tracer download source (no bundling installer), `docs/troubleshooting.md`, `docs/cisco-ios-cheatsheet.md`.

## Acceptance and proof
- [ ] Every lab included in publishable index has complete canonical README and metadata.
- [ ] All published guides pass rubric threshold, link and source checks.
- [ ] No misleading 'answer key' without context, or copied instructor materials.
- [ ] Correct sample CLI and addressing; unresolved device support labeled.
- [ ] Tests/evidence logged and simulator status honest.
- [ ] Restricted legacy files omitted from published count and downloads.
