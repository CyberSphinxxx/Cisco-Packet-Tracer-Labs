## 1. Executive Summary

This report documents the live simulation, technical verification, and deliverable validation for **PTL-0032: HSRP First-Hop Gateway Failover** executed inside Cisco Packet Tracer 9.0.1.

The laboratory topology models an enterprise high-availability default gateway architecture:
1. **Primary Gateway (`Edge-R1`):** A Cisco 4321 ISR serving internal LAN `192.168.1.0/24` on `Gi0/0/1` (`192.168.1.2/24`) and connecting upstream to `Core-R3` on `Gi0/0/0` (`10.10.12.1/30`). Configured with HSRPv2 Group 1 virtual IP `192.168.1.1`, priority `110`, and preemption.
2. **Standby Gateway (`Edge-R2`):** A Cisco 4321 ISR serving internal LAN `192.168.1.0/24` on `Gi0/0/1` (`192.168.1.3/24`) and connecting upstream to `Core-R3` on `Gi0/0/0` (`10.10.23.1/30`). Configured with HSRPv2 Group 1 virtual IP `192.168.1.1`, default priority `100`, and preemption.
3. **Core Upstream Router (`Core-R3`):** A Cisco 2911 router providing core transit between edge routers on `Gi0/0` (`10.10.12.2/30`) and `Gi0/1` (`10.10.23.2/30`), connecting to an external enterprise Web Server on `Gi0/2` (`203.0.113.1/24`), with OSPF Area 0 convergence.
4. **Access Switch (`Switch-S1`):** A Cisco Catalyst 2960-24TT switch aggregating PC clients and edge router LAN interfaces in VLAN 1 (`192.168.1.5/24`).
5. **End Hosts & External Server:** Two LAN clients (`PC1`: `192.168.1.10`, `PC2`: `192.168.1.20`) configured with virtual default gateway `192.168.1.1`, and external `Web-Server` (`203.0.113.100`).
