# Quick persistent checklist (summary, not substitute for phases)

- [ ] 00 Bootstrap: record local HEAD/dirty state and complete inventory
- [ ] 01 Rights: review every legacy file; permission and privacy decisions
- [ ] 02 Architecture: stable category/metadata/templates and tests
- [ ] 03 Migration: only eligible reversible `git mv`; mapping + hashes
- [ ] 04 Existing docs: complete, original, understandable per-lab guides
- [ ] 05 Technical audit: fix Cisco CLI/IPv6/SSH errors; truthfully mark tests
- [ ] 06 New docs: independently researched useful topic coverage, no fake binaries
- [ ] 07 Automation: validator, unit tests, read-only CI
- [ ] 08 Public UX: accurate README, paths, index, contribution docs
- [ ] 09 Final audit: fresh test run + evidence + owner handoff

A checkbox is not proof. Every checked phase must link to its report in `state/reports/`.
